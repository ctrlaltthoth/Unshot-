# Unshot

Turn screenshots into useful things.

- Receipts -> expenses
- Recipes -> shopping lists
- Tickets/confirmations -> packs

## Privacy-first MVP
- On-device OCR and parsing.
- No external AI calls.
- No analytics SDKs.

## Repo
- `ios/Unshot/` SwiftUI app architecture and conversion pipeline.
- `web/unshot-web/` Pack hub for upload, render, merge, export.
- `shared/schema/` Shared JSON schemas.
- `docs/` Architecture, indexing, privacy, App Store checklist, QA.
- `tests/` classifier/parsers/dedupe tests.
